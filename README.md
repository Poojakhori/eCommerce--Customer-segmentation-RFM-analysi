# 🛒 E-Commerce Customer Segmentation & RFM Analysis

## 📌 Project Overview

This end-to-end data analytics project analyzes over **541,000+ online retail transactions** to uncover customer purchasing behavior, identify high-value customers, and generate actionable business insights using **Python, MySQL, and Excel**.

The project demonstrates the complete analytics workflow, including data cleaning, SQL analysis, customer segmentation using the RFM model, and interactive dashboard development.

---

## 🎯 Business Problem

An online retail company wants to:

- Understand customer purchasing behavior
- Identify loyal and high-value customers
- Track sales performance
- Discover top-selling products and countries
- Build customer segments for targeted marketing campaigns

## 🧹 Data Cleaning

Performed using Python and SQL:

- Fixed encoding issues
- Converted InvoiceDate to MySQL DateTime format
- Removed cancelled invoices
- Removed negative quantities
- Removed invalid prices
- Handled missing Customer IDs
- Checked duplicate transactions
- Created cleaned analytical table

---

## 📊 SQL Business Analysis

Performed analysis including:

- Total Revenue
- Monthly Sales Trend
- Sales by Country
- Top Customers
- Best Selling Products
- Highest Revenue Products
- Average Order Value
- Customer Purchase Frequency
- Customer Lifetime Value
- Product Popularity
